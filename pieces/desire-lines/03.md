# Desire Lines #03: The Corner Cut

Alt: A square grid of grey streets with one dark diagonal line running from the lower-left corner to the upper-right corner, cutting every block corner in a single straight run.

Constraint: one polyline, no curves, zero pen-ups. The street grid stays visible underneath.

Pen-up count: 0. Nothing here would be cut. The line crosses four intersections and never follows a street, which is the point: the walker takes the diagonal because the grid asks for two sides of a triangle.

Open question for the next piece: a route with the same start and end but one pen-up at the midpoint, to show where a second walker would stop.
